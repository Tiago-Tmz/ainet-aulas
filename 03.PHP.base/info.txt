Pre-requisites
--------------
Install Docker Desktop


Docker Commands
---------

> Start:
docker-compose up -d


> Stop:
docker-compose down -v


> List running containers
docker-compose  ps


> Execute Comand Inside Container:
docker-compose run NAME_OF_SERVICE COMMAND

Example2:

docker-compose run web bash

docker-compose run composer install


Tailwind CLI Command to build final css file
---------

Execute the command on the web root folder

npx @tailwindcss/cli -i ./resources/css/input.css -o ./public/css/output.css --watch


-----------------------------------------------
> Access to running services:
-----------------------------------------------

> Web Server:
--------------
http://localhost
(Web Server root - folder "web/public")


> Adminer:
-----------
http://localhost:8080


> MySQL:
---------
Container Name = mysql
Host = mysql (ou "localhost" ou "127.0.0.1")
Port = 3306
URL: jdbc:mysql://localhost:3306

Name of Database = mydb
User Root =   root/root
Other User =  dev/dev



-----------------------------------------------
> Notes about PHP composer
-----------------------------------------------

Add the file composer.json to the web root (/web) 

Execute the "composer install" command with the following:
docker compose run composer install
